# Wherobots power for Kiro

Explore catalogs, run spatial SQL, and build geospatial pipelines on Wherobots from Kiro. This power registers the Wherobots MCP server and seven skills.

## Install

In the Kiro IDE, open the **Powers** panel, choose **Add Custom Power**, then **Import power from GitHub**, and enter:

```text
https://github.com/wherobots/agent-skills/tree/main/powers/wherobots
```

## Sign in

Authenticate `wherobots-mcp-server` from the MCP panel in Kiro. Kiro opens a browser so you can sign in to Wherobots and pick an organization.

Setup without the power, including the API key alternative to OAuth, is documented at [Set Up Wherobots in Kiro](https://docs.wherobots.com/develop/agentic-tools/editors#kiro).

## Privacy

Wherobots handles data sent through this power under its [privacy policy](https://docs.wherobots.com/privacy-policy).
